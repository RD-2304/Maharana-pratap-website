# Maharana Pratap Website

This is a comprehensive website dedicated to Maharana Pratap, the legendary Rajput king of Mewar known for his resistance against the Mughal Empire.

## Pages

- **Home**: Introduction and key facts about Maharana Pratap
- **Biography**: Detailed life story, early life, ascension, resistance, and death
- **Timeline**: Chronological events of his life
- **Battles**: Major battles, including Haldighati and guerrilla warfare
- **Legacy**: Cultural impact, patronage of arts, and national hero status
- **Gallery**: Images including portraits, statues, and depictions
- **Contact**: Contact form for inquiries

## Features

- Responsive design with Rajput-themed colors
- Interactive image gallery with navigation
- Smooth scrolling navigation
- Comprehensive historical content
- Mobile-friendly layout
- Browser privacy controls and safer contact email composition

## Technologies Used

- HTML5
- CSS3 (with Grid and Flexbox)
- JavaScript (ES6)

## How to Run

Open `index.html` in a web browser.
